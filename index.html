What is HTML?

HTML stands for HyperText Markup Language. It is used to make the structure of websites.

HTML Headings

Headings are used for titles and subtitles. There are 6 different heading sizes.

This is an h1 heading

This is an h2 heading

This is an h3 heading

This is an h4 heading

This is an h5 heading
This is an h6 heading

The h1 heading is usually the main title. The h6 heading is the smallest.
